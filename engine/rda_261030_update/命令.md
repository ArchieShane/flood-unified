## L2 / L2planned：缺设备参数的设施不生效，页面标明

数据里这些设施只有位置，建不了模型（不编参数），**不放进模型、不生效，但两态照常跑**：
- 临时泵 13 个点（6 吸水 + 7 排水）：只有「6 英寸 × 台数」，没有流量 / 扬程 / 曲线 / 接入节点；
- Geocell 23 个：只有顶 / 底标高和面积，没有进出口连接和流量；
- Planned 泵 `MIT_HS-…_PMP-21`：MODEL_READY = 否，缺曲线、启停水位、湿井。

**页面上怎么看**：点 L2 / L2planned，设施图层列出这一态新增的设备（按「所属态」），每个要素带 `建模状态`：`已建模` 或 `未建模（数据缺参数）`，并有 `说明`（缺什么）。
- L2 新增：临时泵吸水点 6、排水点 7（全部未建模）→ 所以 **L2 的计算结果和 L1 相同**。
- L2planned 新增：已建模的有 Planned 出水口 18、检查井 1、雨水井 1（管线本来就全用）；未建模的有 Geocell 23、Planned 泵 1。
- 交付根的 `00_README.md`、`params.json`（「设施状态与管线状态」组）、`outputs.json`（`states_detail.<态>.unmodeled`）也逐态写明。

## 操作步骤

**0. 先等旧的 1h61mm 测试跑完**（不要停它）：

```bash
data/regions/RDA/RDA-server.sh status
```

**1. 铺脚本和数据**（每台服务器各一次；`<engine>` 是该服务器上 engine 目录）：

```bash
./install.sh <engine>
```

**2. 一条命令：挪开旧结果 + 检查 + 启动**（服务器号 1 / 2 / 3，各自在各自机器上敲这一条）：

```bash
<engine>/scripts/rda-261030.sh 1 go
```

它依次做：
- **挪开旧测试结果（不删）**：只处理本服务器分到的场景，且只处理「有二维结果、但没有输入指纹」的（= 不是用现在这套输入算的）。改名放进 `_old_test_<时间>/`（工作目录里一份、NAS 里一份，相对路径不变，要找回挪回去即可）。有指纹的新结果、别的场景、别的服务器的都不碰。旧测试容器还在跑会拒绝。
- **check**：不通过不启动。
- **启动**。

只想挪开、不启动：`rda-261030.sh 1 archive`。要真删旧数据（不是挪开）：`rda-261030.sh 1 clean`（先 dry-run）、`clean --yes`。

> 为什么要挪：二维结果文件名只含场景和态（`RDA_S61D1_L1_2d.npz`），旧测试留下的同名文件会被当成「续跑」跳过计算，拿旧结果冒充新数据。`run_region` 现在会拒绝使用没有输入指纹的旧结果，所以不挪就启动不了 61mm1h。其余 8 个场景服务器上本来没有旧结果。

**2b. 页面里删旧仿真（先备份，可恢复；新仿真编号接着序列走，旧 #1 删掉后就是 #2）**：

```bash
<engine>/scripts/web-archive-sim.sh <app 目录> 1            # 只打印要做什么
<engine>/scripts/web-archive-sim.sh <app 目录> 1 --yes      # 真做：备份 SQL 转储 + 抽取结果，再 DELETE /api/simulations/1
<engine>/scripts/web-archive-sim.sh <app 目录> --restore <备份目录>   # 恢复
```

**3. 看进度、日志、成果目录**：

```bash
<engine>/scripts/rda-261030.sh 1 status
<engine>/scripts/rda-261030.sh 1 log -f
<engine>/scripts/rda-261030.sh 1 report
```

停止 / 暂停：`rda-261030.sh 1 stop [--pause]`，`resume` 恢复；续跑时已完成的步骤跳过。
