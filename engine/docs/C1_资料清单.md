路径缩写：**仓库** = `D:\阿布扎比\排水智能体`，**WORK** = `D:\swbrain_work\swmm`，**C2D** = `D:\swbrain_work\swmm\c2d`。`{tag}` 指雨 / 计算域版本：R61、R96（原计算域）、U61（客户单元版）、M61（模型版）、D24（24 h 设计暴雨，**已作废**：那次用的还是原计算域，范围不对，2026-10-02 作废）；`{态}` 指 L1 / L2 / L2P / L2S / L2S3。


## 需要说明的几点

- **两份 GDB 是同一份数据**：全市管网重建读压缩包；C1 的泵站、压力管、出水口读解压版。
- **`Mussafah_baseline.inp` 的原始来源待查**：Mussafah_00 交付说明里写的是由客户交付的「治理后」模型剥离出的 L1。C1 只用了它的雨型，不用它的管网。
- **U61 的计算域来自照片描图**：汇水区已定为以客户 22 个模型为准，现在应以 M61 为准。
- **Parsons CAD 文件夹没有直接使用**：C1 的泵站参数取自 PDF 版。
