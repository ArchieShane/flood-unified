# 四个态的定义与建模规则

分级依据客户 SW 分级图：L1 既有永久设施；L2 雨前临时 / 过渡；L3 雨中应急（不在本流程里）。**预置在固定点位的移动泵算 L2**；我们提出的箱涵也记在 L2+ 下。

## L1 现状（`build_c1.py`）
- 管网：全市一维截取，**触及计算域的连通块整块取**（C1：39 块、约 6.7 万井）。旧规则「≥50 % 节点在域内」会丢掉给关键热点排水的大网，已弃用。
- 现状泵站（`c1_existing_pumps.py` 产出清单）：湿井 = 泵站位置那口井，井底加深到「地面 − 客户库井深」；SWMM `PUMP2` 固定流量 = 台数 × 单台；启停按 D13。排进同一个出水口的每台泵各建一个自由出水口（SWMM 出水口只能挂一根管）。客户库里被当成重力管的压力管要删掉换成泵。
- 二维：计算域多边形建非结构三角网；雨：有管网覆盖处经单位线注入一维，离井远的地面直接下在二维上。

## L2 = L1 + 雨前移动泵（`build_c1_l2.py`）
- 点位 = 顾问图纸的移动泵点（C1：OP-02 的 27 点，去掉塘边 4 点 → 23 台）；流量 = 一对一配对的顾问泵站单泵流量。
- 吸水井 = 最近的井；接收井 = 沿管网往下游第一口在参照 L1 结果里**不溢流**的井（2 km 管长内），找不到排最近出水口。
- 结论提醒：移动泵只是在同一张满了的管网里挪水，效果通常很小。

## L2+planned = 顾问方案（`build_c1_l2p.py`）
- 固定泵站：只开主用；湿井按图纸；压力管追到终点，追不到排最近规划塘（标「Claude 自定」）。
- 塘：塘底平于轮廓内地面最低点、1 m 围堤；库容 = 面积 × 1 m；满后溢到塘占地；**塘面不在二维域内的标 `no_surface`**（只在一维收水，溢出记一维损失）。
- 保留 L2 里顾问方案没覆盖的个别移动泵（C1：MP-16）。

## L2+suggested v3（`c1_design_l2s3.py`，每场雨各设计一套）
按**这场雨** L2+planned 的残余积水（全程最大水深 ≥ 0.30 m、在热点汇水区内、不在塘里、离热点 500 m 内、≥ 200 m³ 或 ≥ 0.05 ha）设计：
- **管网接不住**（片内井溢流 ≥ 这片最大积水量一半）→ 转输：12 英寸固定泵（0.36 m³/s/台）从溢流最多的井抽，排到 1.5 km 内**装得下**的规划塘，否则 3 km 内新建出水口，否则箱涵。
- **地表来水** → 地面取水泵（按 3 h 抽完定台数），**直接打进塘的一维节点**，塘到 90 % 即停；没有装得下的塘排新建出水口。
- 塘分配：可用 = 0.9 × 库容 ×（1 − L2+planned 末满度）；转输要的量 = 片内井溢流量，地面取水 = 1.5 × 最大积水量；按积水量从大到小分。
- 进塘的转输泵加 SWMM 控制规则：塘水深 ≥ 0.90 m 停泵（优先级最高）；吸水井 > 0.30 m 开、< 0.05 m 停。
- 箱涵：一维蓄水节点接片内最低的井，容积 = 最大积水量取整到 500 m³，深 3 m。

### 为什么不是 v1 / v2
- **v1 土堤**：把地表水挡在堤外，堤外反而变深（C1 61 mm：堤外 3.9 ha 变深、ADM-90 旁 +0.6 m）→ 弃用。
- **v2**：不看塘装不装得下，小塘被转输泵灌爆、放到塘面上的水漫出塘外（C1：61 mm 变深 2.0 ha、96 mm 11.4 ha）→ v3 修掉后降到 0 / 0.04 ha。
- 规则一变就另起态名（`L2S1` / `L2S` / `L2S3`），旧结果保留作对照，报告里写明弃用原因。
