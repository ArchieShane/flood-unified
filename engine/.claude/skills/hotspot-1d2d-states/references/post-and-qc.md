## 统计口径（写进报告的「口径」）
- 水深 = 三角单元形心水深；< 0.02 m 算干。
- 积水面积 = 全程最大水深 ≥ 0.10 / ≥ 0.30 m 的单元面积；最大积水量 = 逐帧 Σ 水深 × 面积的最大值。
- 分区：各热点汇水区、**并集**（有重叠，不能相加）、热点 200 m 内、管网服务区 / 直接降雨区；换计算域时加对应的汇水区单元（客户单元 / 模型单元）。
- 热点单点：取热点 50 m 内最深（热点坐标是点，积水坑常偏几十米），同时给坐标所在单元的水深。

## 质检（每个态都过一遍）
| 检查 | 通过标准 |
|---|---|
| 算完 | 72 帧（6 h）或 336 帧（28 h）；无 NaN |
| 一维连续性误差（`*_2way.rpt` Continuity Error） | < 2 %（C1：0.8–1.8 %） |
| 一二维交换 | 域内井溢流 = 交给二维的水（差 < 0.2 %）；「一维 Flooding Loss 比交出去多 50–75 %」是域外井的溢流，不是错——域内 + 域外 = 总溢流 |
| 二维水量 | 1D→2D + 雨 − 2D→1D − 进塘 − 泵出 = 域内留存 + 边界出流 |
| 最深点 | 查 50 m 内最低地面、200 m 中位地面：是封闭洼地就正常，否则查地形 / 交换 |
| 副作用 | L2+suggested 比 L2+planned 变深的面积（v3 应接近 0）；塘满溢出量 |
| 设施容量 | 泵「能力用了」= 抽水量 ÷（额定 × 模拟时长）；≥ 70 % 满负荷、< 20 % 闲着；排放点有没有接不住 |

## 解释结果前先核算
差别大时先定位来源再下结论。例：C1 原计算域 L1 下 ≥0.30 m 积水 25.5 ha，客户单元版只有 3.9 ha——核算发现 21.3 ha 在客户单元以外（13.9 ha 在内陆 RD-2、20.0 ha 在无管网直接降雨区），不是方案差异。
